  <h1>📺 Netflix India – Landing Page Clone</h1>
  <p class="lead">A clean, responsive HTML/CSS clone of the Netflix India landing page.</p>

  <h2>📌 Project Name</h2>
  <p><strong>Netflix India – Landing Page Clone</strong></p>

  <h2>📌 Short Description</h2>
  <p>A pixel-perfect replica of the Netflix India homepage, rebuilt using HTML and CSS with responsive UI, hero section, images, videos, and FAQ components.</p>

  <h2>📌 Key Features</h2>
  <ul>
    <li>🎨 High-fidelity Netflix UI clone</li>
    <li>📱 Fully responsive layout</li>
    <li>🎥 Embedded autoplay videos</li>
    <li>🧭 Navigation bar with buttons</li>
    <li>🔍 FAQ hover interaction</li>
    <li>🌗 Netflix-like dark theme</li>
  </ul>

  <h2>📌 Tech Stack</h2>
  <table>
    <tr><th>Technology</th><th>Usage</th></tr>
    <tr><td>HTML5</td><td>Base structure</td></tr>
    <tr><td>CSS3</td><td>Styling and responsiveness</td></tr>
    <tr><td>Google Fonts (Poppins)</td><td>Typography</td></tr>
    <tr><td>Local Assets</td><td>Images & Videos</td></tr>
  </table>

  <h2>📌 Installation Steps</h2>
  <p><strong>Prerequisites:</strong> None</p>
  <pre>
# Clone repository
git clone https://github.com/yourusername/netflix-clone.git

# Navigate
cd netflix-clone

# Open file
open index.html
  </pre>

  <h2>📌 Usage Instructions</h2>
  <p>Simply open <code>index.html</code> in any browser. No server required.</p>
